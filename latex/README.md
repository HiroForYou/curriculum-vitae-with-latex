# Cristhian Sanchez's LaTeX CV

This folder contains all the sources, assets, and build output for the résumé. The template is free to reuse and adapt to your own needs.

## Main files

- `en/` and `es/`: one folder per language, each with its own `cv.tex` (main
  document and personal details) and `section_*.tex` files (the CV's
  sections). Both versions share everything below, so their content stays
  independent but their look stays identical.
- `yaac-another-awesome-cv.cls`: the shared LaTeX class and styles.
- `darwiin.png` and `fonts/`: the shared photo and typefaces.
- `output/`: the PDFs and auxiliary files generated by the build (one pair
  per language, e.g. `sanchez_saune_cristhian_CV.pdf` and
  `sanchez_saune_cristhian_CV_es.pdf`).

## Editing

Edit `en/cv.tex` or `es/cv.tex` to update the header, links, and personal
details for that language. Edit the matching `section_*.tex` file inside
that same folder to change a specific section. Keep both languages in sync
manually — there's no automatic translation between them.

The build runs from `infra/compile.ps1` (`-Lang en|es|both`) and requires the `sharelatex` container to be up, along with `mongo` and `redis`. It compiles with the working directory set to `latex/` itself and `en/cv.tex` or `es/cv.tex` passed as the target file — that's why every `\input` inside those files is prefixed with `en/` or `es/`, and why the shared class/photo/fonts are referenced by their bare names (relative to `latex/`, not to the language subfolder). Changing that working directory (e.g. compiling from inside `en/`) breaks the build: with `-output-directory` then pointing outside the compiler's own directory tree, `hyperref`/`rerunfilecheck` fail at the very end with a cryptic `cannot find file ''`, even though the whole document compiled fine up to that point.

In `en/section_experience_short.tex`, the Seidor experience is declared with
the same `\experience` command as the others: the description and the
clients go together in the eighth argument, and each client is composed with
`\clientblock{<client>}{<sector>}{<achievements>}`. That way the whole
consulting engagement occupies a single table row, just like every other
entry — `\experience` wraps that argument in a `minipage`, which `longtable`
can only place whole on a page, never split.

`es/section_experience_short.tex` writes that same entry differently: as
loose `longtable` rows instead of one `\experience` call, with each
`\clientblock` on its own `&`-prefixed row. See "Fine-tuning the spacing"
below for why.

## Fine-tuning the spacing

The class exposes named lengths for the vertical rhythm, instead of scattering
values across the macros:

- `\cvrowheadsep`: an experience's header → body.
- `\cvtagrowheight`: the height of the technology-tag row. The body is a
  `minipage[t]`, whose depth always exceeds a `\\[...]`; that's why the space
  above the tags is controlled by that row's height rather than by the
  separator.
- `\cvrowtagsep`: technologies → next experience.
- `\cvclientpresep` and `\cvclientpostsep`: space before and after a client
  header.
- `\cvprojecttagsep`: space before a project's tags.

Automatic hyphenation is disabled (`\hyphenpenalty=10000`) and `\frenchspacing`
is used: lines are justified by compressing the whitespace, which produces a
few expected `Overfull \hbox`. The experiences' right-hand column (`E`) is
justified, not ragged.

The expected output is:

```text
output/sanchez_saune_cristhian_CV.pdf      (English)
output/sanchez_saune_cristhian_CV_es.pdf   (Spanish)
```

Spanish text runs noticeably longer than English. The Seidor entry (5
`\clientblock`s) is the tallest single item in the résumé, and once
translated it no longer fits in the space left on page 1 after Skills.
`longtable` never splits a single row across a page break — normally, if a
row doesn't fit, the *entire* row (the whole Seidor body, wrapped in a
`minipage` by `\experience`) jumps to the next page, leaving a large blank
gap behind on page 1. A `\newpage` before the section title avoids the gap,
but then "Experiencia Profesional" and Seidor's header don't appear on page 1
at all, unlike the English version.

`es/section_experience_short.tex` fixes this at the root instead: Seidor's
entry is written as loose `longtable` rows (see `\textbf{Junio 2025} & ...`)
rather than a single `\experience` call, with each `\clientblock` on its own
row (`& \clientblock{...} \\`). Since nothing wraps them in a `minipage`
anymore, `longtable` can break between any two clients, same as it already
does between unrelated experiences — so the first four clients fill out page
1 and only the fifth (Innova Sports) flows to page 2, with no forced break
and no blank gap.
