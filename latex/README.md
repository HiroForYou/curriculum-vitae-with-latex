# Cristhian Sanchez's LaTeX CV

This folder contains all the sources, assets, and build output for the résumé. The template is free to reuse and adapt to your own needs.

## Main files

- `cv.tex`: main document and personal details.
- `section_*.tex`: the CV's sections.
- `yaac-another-awesome-cv.cls`: the LaTeX class and styles.
- `darwiin.png` and `fonts/`: the photo and typefaces used by the document.
- `output/`: the PDF and auxiliary files generated by the build.

## Editing

Edit `cv.tex` to update Cristhian Sanchez's header, links, and personal details. Edit the matching `section_*.tex` file to change a specific section.

The build runs from `infra/compile.ps1` and requires the `sharelatex` container to be up, along with `mongo` and `redis`.

The Seidor experience is declared with the same `\experience` command as the
others: the description and the clients go together in the eighth argument,
and each client is composed with `\clientblock{<client>}{<sector>}{<achievements>}`.
That way the whole consulting engagement occupies a single table row, just
like every other entry.

## Fine-tuning the spacing

The class exposes named lengths for the vertical rhythm, instead of scattering
values across the macros:

- `\cvrowheadsep`: an experience's header → body.
- `\cvtagrowheight`: the height of the technology-tag row. The body is a
  `minipage[t]`, whose depth always exceeds a `\\[...]`; that's why the space
  above the tags is controlled by that row's height rather than by the
  separator.
- `\cvrowtagsep`: technologies → next experience.
- `\cvclientpresep` and `\cvclientpostsep`: space before and after a client
  header.
- `\cvprojecttagsep`: space before a project's tags.

Automatic hyphenation is disabled (`\hyphenpenalty=10000`) and `\frenchspacing`
is used: lines are justified by compressing the whitespace, which produces a
few expected `Overfull \hbox`. The experiences' right-hand column (`E`) is
justified, not ragged.
